Projetos pessoais de impressão 3D, robótica e automação. Tudo aqui é **beta**: em desenvolvimento e ainda não comprovado.

> Personal projects in 3D printing, robotics and automation. Everything here is beta: in development and not yet proven.

Os projetos foram desenvolvidos por mim com assistência de ferramentas de IA.

## Projetos

| Projeto | O que é | Estado |
|---|---|---|
| [kobra3v2-orca-plugin](https://github.com/okamisolutions/kobra3v2-orca-plugin) | Três plugins Python independentes para o OrcaSlicer funcionar com a Anycubic Kobra 3 V2 e o ACE Pro: metadados para a tela, purga depois da carga e espera da mesa | Em uso |
| [rinkhals-discovery-helper](https://github.com/okamisolutions/rinkhals-discovery-helper) | App do Rinkhals que mantém a impressora no grupo multicast SSDP, para o Anycubic Slicer Next achá-la em modo LAN | Funcionou; reinicialização não testada |
| [kobra3-calibracao](https://github.com/okamisolutions/kobra3-calibracao) | Modelos, pós-processadores de G-code e geradores de testes de calibração da primeira camada | Parte testada |
| [vigia-impressao](https://github.com/okamisolutions/vigia-impressao) | Monitor local de impressão com detector de falhas (modelo do Obico em ONNX) e pausa automática | Em uso |
| [claude-code-voz](https://github.com/okamisolutions/claude-code-voz) | Voz local para o Claude Code em cinco peças independentes: leitura das respostas, aceleradores com CUDA graphs (Chatterbox 4,7× e Qwen3-TTS 3,8× o tempo real, com o mesmo áudio), ouvido pelo microfone e barra de controles | Em uso |
| [sensor-flex-grafite](https://github.com/okamisolutions/sensor-flex-grafite) | Moldes paramétricos no Fusion para sensores de dobra de silicone condutivo, para uma luva que comanda uma mão robótica | Projetado; não impresso |
